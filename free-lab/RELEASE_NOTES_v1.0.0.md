# Free Resume Lab v1.0.0

This free download demonstrates one narrow behavior with fixed local fixtures:
after a forced process stop, a new process skips the durably completed record
before fetching it again.

Requirements:

- Python 3.10 or newer
- No third-party package
- No network request during execution

Extract the ZIP and run:

```text
python free-lab/run_demo.py
```

This is not the paid configurable Pipeline Kit and is not a performance claim
for arbitrary websites. The paid kit adds configurable selectors and fields,
Playwright collection, retry policy, logs, reports, and full source tests.
